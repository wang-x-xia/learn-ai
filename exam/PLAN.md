### 1.3 数据格式


### 1.4 发现的问题
1. **题目格式不统一**：

   - 选择题格式：`1.` 或 `(1)`
   - 选项格式：`(A)` 或 `A、` 或 `（A）`
2. **操作技能题目未解析**：第4、6部分为操作技能题目，格式可能不同

## 三、技术架构

### 3.1 技术方案
**在 MkDocs 中嵌入独立页面**
- 在 `docs/exam/` 下创建单页应用（SPA）
- 使用纯 HTML + JavaScript，暂不涉及复杂样式
- 访问路径：`https://wang-x-xia.github.io/learn-ai/exam/`
- 优点：与主站点集成、统一导航、开发简单

### 3.2 目录结构
```
docs/exam/
├── index.html          # 单页应用，包含所有功能
├── js/
│   ├── data.js        # 题库数据（内嵌 JSON）
│   └── app.js         # 所有逻辑
```

**开发策略**：
- **第一阶段**：纯功能实现，使用最基础 HTML，暂不涉及样式
- **第二阶段**：功能验证通过后，再添加 CSS 样式

### 3.3 MkDocs 配置
```yaml
nav:
  - 首页:
    - index.md
    - 模拟考试: exam/index.html
```

## 四、从资料到题库的流程

### 4.1 资料解析流程
```
原始文档（.doc/.docx）
    ↓
使用 python-docx 解析
    ↓
提取题目文本、选项、题型
    ↓
提取答案（从答案部分）
    ↓
标准化格式（去除括号、统一编号）
    ↓
生成 JSON 数据
    ↓
内嵌到 data.js
```
