## 知识库结构

- **基础理论** — Transformer、KV Cache、Mamba/SSM、多模态、扩散模型、表示学习
- **应用技术** — AI Agent、记忆系统、工具接入、RAG、推理经济性等
- **前沿研究** — 可解释性、AI 安全与治理
- **模型档案** — 重要模型深度技术分析
- **产品档案** — 编码 Agent、个人 Agent、Agent Workflow 框架、开源库
